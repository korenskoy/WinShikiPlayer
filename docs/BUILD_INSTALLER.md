# Сборка установочных пакетов

Для запроса «собери инсталлер» используйте **`Build-Installer.ps1`**. Скрипт собирает автономный комплект из текущих исходников, подготавливает обновление с новой версией и не устанавливает его на компьютер.

## Команда

Нужны PowerShell 7, .NET SDK и зависимости WinUI-проекта. Инструменты Windows SDK выбираются из версии `Microsoft.Windows.SDK.BuildTools`, указанной в csproj.

```powershell
.\Build-Installer.ps1
```

`Build-Installer.cmd` запускает эту же команду через PowerShell 7. Исходники можно обновлять обычным способом, затем повторять команду при каждом выпуске.

## Версия

- По умолчанию повышается последний компонент MSIX-версии: `0.2.0.10` → `0.2.0.11` → `0.2.0.12`.
- Учитываются версия исходного манифеста и уже выпущенные ZIP. Старые установщики не перезаписываются.
- Явная новая версия: `./Build-Installer.ps1 -Version 0.3.0`. Трёхкомпонентная версия становится `0.3.0.0`.
- Явная версия должна быть новее существующих выпусков. Каждый компонент — от 0 до 65535.
- В собранных EXE/DLL и MSIX используется одна версия. Исходный `packaging/AppxManifest.xml` обновляется после успешных проверок и создания ZIP. При ошибке он остаётся прежним.

## Что выполняется

1. Консольные тесты Core в Release; при ошибке выпуск прекращается.
2. Очистка только выделенных каталогов публикации и staging внутри `artifacts`, затем Release-публикация. Удалённые из проекта DLL не остаются в новом пакете.
3. Создание и подпись MSIX существующим локальным сертификатом.
4. Проверка подписи, версии, издателя, x64, OAuth-протокола, XBF/PRI и libass. Локальная конфигурация, ключи подписи и пользовательские данные не допускаются в пакет.
5. Подготовка автономного установщика и его запуск с `-CheckOnly` в штатном Windows PowerShell 5.1: без установки и изменения сертификатов.
6. ZIP из шести ожидаемых файлов, проверка состава и SHA-256; сборка, подпись и `--check-only` единого EXE, затем сохранение версии и `latest.json`.

Скрипт не добавляет сертификаты в доверенные и не закрывает установленное приложение. Проверка подписи использует текущие доверенные сертификаты Windows. На этой машине сертификат разработки уже установлен.

## Результат

Основной файл для пользователей — **WinShikiPlayer-<версия>-Setup-x64.exe**. Это подписанная оболочка, содержащая проверенный ZIP/MSIX и публичный сертификат. Она проверяет SHA-256 встроенного пакета, устанавливает его через штатный Windows PowerShell и удаляет только шесть собственных временных файлов. Проверка без установки: `WinShikiPlayer-<версия>-Setup-x64.exe --check-only`. Установщик не требует отдельно устанавливать .NET или Windows App SDK; используется также штатный .NET Framework Windows 10.

Общие ключи приложения включаются из `appsettings.local.json`, если файл существует. Берутся только Client ID/Secret, Redirect URI, домен и User-Agent Shikimori и токен Kodik. Для сборки без них используйте `-WithoutApplicationKeys`. Личные сессии и ключ подписи не встраиваются.

В `artifacts/installer`:

```text
WinShikiPlayer-<версия>-Setup-x64.zip
WinShikiPlayer-<версия>-Setup-x64.exe
WinShikiPlayer-<версия>-Setup-x64.exe.sha256
WinShikiPlayer-<версия>-Setup-x64.zip.sha256
WinShikiPlayer-<версия>-x64.msix
WinShikiPlayer-development.cer
latest.json
```

В ZIP — MSIX, публичный сертификат, `Install.cmd`, `Install.ps1`, `installer.json`, `README.txt`. Получателю достаточно распаковать архив и запустить `Install.cmd`.

Журнал сборки — `artifacts/installer-build-<версия>.log`. Распакованный комплект — `artifacts/installer-kits/WinShikiPlayer-<версия>-Setup-x64`.

## Параметры и локальные данные

`-SkipTests` явно пропускает тесты; обычный выпуск выполняйте без него. Сборка прекращается при ошибках публикации, подписи или проверки комплекта.

`appsettings.local.json`, OAuth-сессии и история в архив не включаются. Существующие данные сохраняются при установке обновления.

Сохраняйте `artifacts/signing`: там находятся приватный сертификат и пароль, защищённый DPAPI текущего пользователя Windows. Каталог исключён из Git и не попадает в установщик. Обычная сборка очищает staging и публикацию, сохраняя данные подписи.
